# 로스트아크 게임속 아이템들의 시세예측

### 프로젝트 동기
게임내 재화가 많이쌓여서 이를 소모해 캐릭터를 강화하려고 강화에 필요한 아이템을 구매하였는데 다음날 보니 해당 아이템의 가격이 훨씬 저렴했다 (눈탱이 맞은 기분)

아이템의 미래의 가격흐름양상을 예측해주면 좋을것 같다는 생각이 들게됨<br><br><br>
